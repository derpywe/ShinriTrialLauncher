# Shinri Trial Launcher

Неофициальный десктопный лаунчер для комьюнити-мода **Shinri Trial**
(GMod, в духе Danganronpa). Не имеет отношения к команде разработки
проекта — независимая инициатива сообщества игроков.

## Что это

Удобная и лёгкая альтернатива стандартному серверному браузеру GMod. 
Лаунчер объединяет в себе мониторинг серверов, интеграцию со Steam, 
аналитику игроков и автоматизацию рутинных действий.

## Главные возможности

### 🌐 Сервера и подключение
- Список лобби (RU и ENG) с живым статусом: карта, количество игроков, пинг.
- Подключение к серверу в один клик через Steam.
- **Умная очередь:** если сервер полон или недоступен (перезапуск), лаунчер 
  встанет в ожидание и автоматически подключит тебя, как только появится место.
- Вкладка «Последние сервера» с историей твоих заходов.

### 👥 Друзья и Steam
- Интеграция со Steam Web API.
- Показывает, кто из друзей сейчас играет в GMod и на каком конкретно сервере.
- Уведомления в трее, когда друг заходит в одно из лобби проекта.
- Встроенный поиск профилей Steam с детальной статистикой (VAC-баны, 
  налетанные часы в GMod, аватары и т.д.).

### 📊 Аналитика, База игроков и История
- **Парсинг консоли:** лаунчер читает `console.log` игры и автоматически 
  разбирает вывод команды `status`.
- Наглядный список игроков на сервере с аватарами, пингом и временем игры.
- **Личная база встреч:** лаунчер запоминает, с кем и когда ты пересекался. 
  Можно оставлять личные заметки на игроков (например, если кто-то насолил).
- **История быстрых игр:** лаунчер автоматически выделяет сессии «Быстрых игр» 
  и сохраняет полный состав участников.

### 🕵️ Поиск по UID (ShinriReviews)
- Встроенный поиск игроков по UID или нику в базе отзывов `shinrireviews.com`.
- Показывает аватарку, историю прошлых ников и все отзывы об игроке с 
  возможностью сортировки.

### 🔔 Уведомления и Обновления
- Встроенный центр уведомлений (иконка колокольчика в шапке).
- Автоматическая проверка новых версий лаунчера на GitHub.
- При выходе нового релиза появляется уведомление с кнопкой перехода 
  на страницу скачивания.

### 🎨 Интерфейс и Система
- Тёмный интерфейс в стиле проекта с кастомным заголовком окна.
- Сворачивание в системный трей (чтобы не мешать во время игры).
- Все настройки и кэш сохраняются локально в `AppData`.

## 🛠 Как это настроить и использовать

Чтобы лаунчер работал на полную мощность, нужно выполнить пару простых действий.

### 1. Вкладка «Друзья» (Steam API)
Чтобы видеть, на каком сервере играют твои друзья:
1. Зайди в **Настройки** (шестерёнка вверху) и нажми **«Получить ключ»**.
2. В открывшемся окне Steam создай Dev API ключ (если его еще нет). 
   В поле «Домен» напиши любое слово, например `localhost`.
3. Скопируй полученный ключ и вставь его в настройки лаунчера.
4. Там же укажи ссылку на свой профиль Steam (или твой SteamID64).

### 2. Вкладка «Консоль» и команда `status`
Чтобы лаунчер видел, кто находится на сервере вместе с тобой:
1. В Steam нажми правой кнопкой мыши по Garry's Mod -> **Свойства**.
2. В поле **«Параметры запуска»** добавь команду `-condebug`.
3. Запусти лаунчер, перейди во вкладку **«Консоль»**, нажми **«Обзор»** и 
   выбери файл `console.log` (он лежит в папке `garrysmod`). Теперь лаунчер 
   будет читать игру в реальном времени.

**Что такое `status`?** 
Это буквально команда в самой игре (открывается консоль на клавишу `~`). 
Она возвращает список всех игроков на сервере и их SteamID. 
- Ты можешь забиндить её на удобную кнопку, а можешь просто писать вручную.
- Написал `status` — лаунчер мгновенно обновил список игроков у себя.
- Рекомендуется писать её хотя бы раз в начале быстрой игры, чтобы видеть, с кем играешь.

### 3. Вкладки «Игроки» и «История игр»
- Во вкладке **«Игроки»** сохраняются все люди, с которыми ты когда-либо 
  пересекался на серверах (при условии, что ты прописывала `status`).
- Если нажмешь на игрока, откроется карточка, где можно **оставить заметку**. 
  Кто-то токсичил или наоборот круто отыграл? Запиши это. При следующей 
  встрече лаунчер подсветит его, и ты сразу вспомнишь, кто это.
- Во вкладке **«История игр»** автоматически собираются все твои сессии 
  «Быстрых игр». Клик по игре покажет полный список участников.

### 4. Поиск по UID
Просто введи UID (например, `#3865`) или ник игрока во вкладке **«Поиск по UID»**. 
Лаунчер подтянет информацию с сайта отзывов: аватарку, историю ников и все 
написанные на него ревью.

## Технологии

- **Python 3**
- **PyQt6** (графический интерфейс)
- **python-a2s** (протокол Source Engine Query для опроса серверов)
- **requests** (Steam Web API, проверка обновлений и парсинг отзывов)
