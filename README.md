# Shinri Trial Launcher (MVP)

## Установка

```bash
pip install -r requirements.txt
python main.py
```

## Как добавить сервера

Открой `servers.py` и впиши реальные IP и порты:

```python
LOBBIES = [
    ("123.45.67.89", 27015, "Lobby #1"),
    ("123.45.67.90", 27016, "Lobby #2"),
]

OFFICIAL_SERVERS = [
    ("123.45.67.100", 27015, "Official Hub #1"),
]
```

Порт — игровой порт GMod (обычно начинается с 27015), не RCON-порт.

## Как это работает

- **Опрос серверов** — через протокол A2S_INFO (`python-a2s`), тот же
  публичный протокол, что использует встроенный серверный браузер Source-игр.
  Получаем название сервера, карту, кол-во игроков/макс, пинг.
- **Подключение** — кнопка "Подключиться" открывает
  `steam://connect/IP:PORT`, что запускает Steam → GMod → сразу
  коннектит к серверу (нужен установленный Steam с зарегистрированным
  протоколом `steam://`, это стандартное поведение).
- **Автообновление** — раз в 15 секунд (`REFRESH_INTERVAL_MS` в `main.py`).
- **Асинхронность** — опрос идёт в пуле потоков, чтобы не подвешивать
  интерфейс, пока сервер не отвечает.

## Файлы проекта

- `main.py` — GUI (PyQt6), таблицы, вкладки, автообновление
- `server_query.py` — обёртка над A2S-запросами
- `servers.py` — список серверов (сюда вписываешь свои IP)
- `requirements.txt` — зависимости
