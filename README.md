# Shinri Trial Launcher

Неофициальный десктопный лаунчер для комьюнити-мода **Shinri Trial** (GMod). 
Это удобная и лёгкая альтернатива стандартному серверному браузеру игры, 
которая объединяет в себе всё необходимое для комфортной игры.

## Что умеет лаунчер?

### 🌐 Поиск серверов и подключение
- **Список лобби:** Отдельные вкладки для RU и ENG серверов с живым 
  отображением карты, количества игроков и пинга.
- **В один клик:** Подключение к любому серверу прямо из лаунчера.
- **Умная очередь:** Если сервер переполнен или перезагружается, лаунчер 
  встанет в ожидание и автоматически зайдёт в игру, как только появится место.
- **История:** Вкладка с твоими последними подключениями, чтобы быстро 
  вернуться на знакомый сервер.

### 👥 Друзья и профили Steam
- **Слежка за друзьями:** Лаунчер покажет, кто из твоих друзей сейчас играет 
  в GMod и на каком сервере. К ним можно присоединиться в один клик.
- **Уведомления:** Если друг заходит в одно из лобби проекта, лаунчер 
  пришлёт всплывающее уведомление.
- **Разведка:** Встроенный поиск профилей Steam. Покажет аватар, часы в 
  GMod, наличие банов и другую полезную информацию об игроке.

### 📊 База игроков и аналитика
- **Список игроков онлайн:** Лаунчер умеет читать игровую консоль и 
  показывать список всех, кто сейчас находится на сервере, с их аватарами 
  и пингом.
- **Личные заметки:** Лаунчер запоминает всех, с кем ты играл. Ты можешь 
  оставлять заметки на игроков (например, «хороший РПшер» или «тимит»), 
  чтобы не забывать их. Есть удобный поиск по базе.
