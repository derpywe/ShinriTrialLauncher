# Shinri Trial Launcher

Неофициальный десктопный лаунчер для комьюнити-мода **Shinri Trial**
(GMod, в духе Danganronpa). Не имеет отношения к команде разработки
проекта — независимая инициатива сообщества игроков.

## Что это

Лёгкая альтернатива стандартному серверному браузеру GMod: список
лобби с живым статусом (карта, количество игроков, пинг) и
подключение к серверу в один клик, без лишних действий в самой игре.

## Возможности

- Список лобби с автообновлением статуса каждые несколько секунд
- Подключение к серверу одним кликом (через Steam)
- Блокировка подключения к переполненным серверам
- Кнопка быстрого входа в игру с приоритетом избранного лобби
- Системный трей вместо полного закрытия приложения
- Подборка полезных ссылок сообщества (гайдбук, отзывы, аддоны)
- Тёмный интерфейс в стиле проекта, с кастомным заголовком окна

## Технологии

Python, PyQt6, протокол A2S (Source Engine Query) для опроса
серверов.

## Статус

Ранняя версия, активно дорабатывается.
